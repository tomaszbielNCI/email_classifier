# Examples

This directory contains example scripts and usage patterns for the email classifier project.

## Available Examples

### simple_test_example.py
A basic test script demonstrating the core functionality of the email classifier.

### load_model_example.py
Example showing how to load and use a pre-trained model for email classification.

## Running Examples

```bash
# Run the simple test example
python examples/simple_test_example.py

# Run the model loading example
python examples/load_model_example.py
```

Make sure you have the project dependencies installed before running these examples.
